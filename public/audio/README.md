# Mixq audio assets

The six WAV loops in this directory are original procedural recordings generated by [`scripts/generate-audio.mjs`](../../scripts/generate-audio.mjs). They contain no third-party recordings or samples and may be used and redistributed with the Mixq project.

Each file is a deterministic 16-second mono PCM loop at 24 kHz. The generator uses cyclic noise and periodic modulation so the boundary behaves like an ordinary adjacent sample transition. Running `npm run generate:audio` recreates every file and fails if a loop boundary exceeds five times its average sample-to-sample change.
